# 26-DS-G-Signal-Analysis
# 代码见Tag V1
  本装置针对2026年全国大学生电子设计竞赛G题《周期信号测量分析装置》
设计实现一套高精度、强抗干扰的时 / 频域一体化周期信号检测系统。 
硬件以 STM32F407ZGT6 为核心处理单元；前端信号调理电路搭载BNC输入
过压与 ESD 防护模块，搭配 1.65V 精密直流偏置电路实现交流信号单极性适
配，采用 MS8312 高速运放搭建八级 Sallen-Key 有源 RC低通滤波器，截止频
率 550kHz，对 1MHz 及以上单频干扰抑制深度超 50dB，后级增设低噪声同相放
大电路，适配 50mV~250mV 全幅值输入范围。 
软件依托 STM32F4 内置三路12位 ADC，采用定时器同步触发多 ADC 多模
架构配合 DMA 循环传输，实现 6MSPS 高速同步采样；程序采用 Goertzel 单
频点频谱分析结合最小二乘拟合算法解析多谐波分量。

  系统主要由信号防护偏置电路、8阶低通滤波器、固定增益放大电路、电源与参考
电压源、STM32F407ZGT6 主控与采集模块及7寸LCD显示屏六部分组成。
